# 0.5.0

## 亮点

- **多个任务同时跑**：在 Voyager 弹窗的本地桥卡片里打开「并行运行任务」后，`voyager serve` 能同时跑多个任务，每个任务各用一个 ChatGPT 标签页，不用再排在别人一小时的长回答后面。最多 10 个，可以在 `~/.voyager/config.json` 里用 `"maxParallelJobs"` 调小。输入和点击仍然轮流进行；往同一个对话发、或改动项目的任务仍会被挡下（`busy`，退出码 5）。开关关着或扩展是旧版时，行为和以前一样，一次一个。需要 Voyager 2.2.1 或更高版本。

## 其他

- `voyager status` 会列出正在跑的任务数和上限（`activeJobs`、`maxJobs`）。
- 几个任务同时上传项目时，记录的文件指纹不再互相覆盖。
- `contrib/web-pro-kit`：`drive_request.py` 和 `drive_mirror.py push` 在本机加锁，两个 agent 同时用时不会丢请求或写错镜像。
- 依赖的 `@voyager-crew/bridge-protocol` 升到 0.5.0。
